# Contributing

Thanks for helping improve OpenLux Pricing Plugin.

## Development

Requirements:

- Node.js 20 or newer
- npm

Install dependencies and run checks:

```sh
npm ci
npm run check
```

Keep changes focused. Add or update tests for behavior changes. Do not commit
`node_modules`, `dist`, coverage output, credentials, or local OpenCode config.

## Pull Requests

Describe the problem, change, and verification performed. Link related issues
when applicable. Keep generated files out of commits; `dist` is generated by
the `prepack` script during publishing.

Maintainers review compatibility with OpenCode plugin types, startup behavior,
pricing correctness, and failure handling.

## Commit And Release

Use concise imperative commit messages. Maintainers publish releases from
GitHub after updating `CHANGELOG.md` and creating a matching version tag.
