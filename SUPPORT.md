# Support

Use GitHub Issues for reproducible bugs and feature requests:
<https://github.com/min0ru/openlux-pricing/issues>

Before opening an issue, run `npm run check` if working from source and search
existing issues. Include OpenCode version, plugin version, Node.js version,
configuration shape without secrets, and relevant sanitized logs.

Use `SECURITY.md` for security reports. Use Discussions or an issue for usage
questions; do not include API keys or private account information.
