# Security Policy

## Supported Versions

Only the latest published version receives security fixes.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability. Email
2010min0ru@gmail.com with:

- A description of the issue and affected version
- Reproduction steps or a proof of concept
- Potential impact

You will receive an acknowledgement when possible. Please allow time for
investigation and a coordinated fix before public disclosure.

This plugin does not handle OpenCode credentials. Never include credentials,
tokens, or private pricing data in a report.
